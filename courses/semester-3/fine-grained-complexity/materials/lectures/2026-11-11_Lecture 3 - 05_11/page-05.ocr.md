# Visibility Problems

## Point-to-Point Visibility
Input: Points $p, q$, and $n$ opaque line segments
Output: Can $p$ see $q$?
$O(n)$

## Point-to-Segment Visibility
Input: Point $p$, line segment $q$, $n$ line segments
Output: Can $p$ see $q$?
$O(n \log n)$
