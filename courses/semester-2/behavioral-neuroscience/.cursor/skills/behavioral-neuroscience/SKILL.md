# Behavioral Neuroscience Study Workflow

This course uses **typed PDF lecture materials** instead of the handwritten OneNote notes found in other courses in this repository.

## Material Locations

- **Lectures:** `materials/lectures/`
- **Assignments:** `materials/assignments/`
- **Syllabus:** `materials/syllabus/`

## How to Study and Answer Questions

1. **Read PDFs Directly:** Use the `Read` tool on the `.pdf` files in `materials/lectures/`.
2. **No OCR Needed:** You do not need to look for `page-XX.ocr.md` or `page-XX.png` files. There is no OneNote sync or OCR workflow for this course.
3. **Citation:** When referencing course material, cite the PDF filename and the page number provided by the `Read` tool's output.
4. **Context:** If questions involve biological mechanisms or neural pathways, lean on the text in the official lecture PDFs as the primary source of truth.

## Overrides
- Ignore the `lecture-notes` and `sync-lectures` skills for this course.
- Use the `read-pdfs` rule for all materials.
